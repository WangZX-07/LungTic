## 主要功能

本系统 LungTic 是一款面向4D肺癌CT影像诊断与预测的桌面端医学软件，集成了医学影像管理、深度学习AI分析、三维可视化等核心能力，为临床医生和医学研究人员提供一站式的肺癌评估工具。系统采用B/S混合架构，前端基于Vue 3和Electron桌面框架，后端基于FastAPI和PyTorch深度学习框架，数据库采用MySQL关系型数据库。

（一）多角色权限管理。系统支持患者、医生、管理员三种角色，每种角色拥有差异化的功能访问权限和界面展示。患者登录后仅能查看本人的检查记录和关联的医生信息，严格保障患者数据隐私；医生拥有完整的患者管理、影像浏览和AI分析功能；管理员则可进行批量用户创建、角色分配、权限管理等系统运维操作。用户认证采用JWT令牌机制，结合bcrypt密码哈希算法确保账号安全，同时集成文本验证码功能防止恶意登录攻击。

（二）医学影像数据管理。系统支持DICOM标准格式和NIfTI格式医学影像的批量上传、解析与存储。上传时自动提取DICOM标准中的患者ID、检查实例UID、序列UID、切片位置等关键元数据，并按照Study-Series-Slice三级层级结构组织存储。系统支持4D CT影像数据，可将不同呼吸时相的CT序列自动分组（10个时相，每个时相包含若干层切片），为后续的时间维度分析提供数据结构基础。用户上传时可手动指定患者编码，灵活满足临床工作流程需求。

（三）AI肿瘤自动分割。系统集成了Attention U-Net深度学习模型，能够对CT影像中的肺部肿瘤区域进行全自动分割。该模型采用编码器-解码器架构，在跳跃连接中引入注意力门控机制，有效聚焦于肿瘤区域特征。用户仅需一键操作，系统即可自动完成整个检查序列中所有切片的逐层推理和分割，并输出Dice相似系数作为分割质量评估指标。分割结果以二值Mask形式叠加显示在原始CT图像上，支持透明度调节。

（四）IGTV三维靶区重建。针对4D CT的多时相特性，系统基于各时相的分割结果，采用逻辑或运算融合所有时相的肿瘤区域，再利用Marching Cubes等值面提取算法生成肿瘤内靶区的三维三角网格模型。重建结果在Three.js引擎中进行三维渲染，用户可自由旋转、缩放视角，切换实体或线框显示模式，直观观察靶区的空间形态。系统自动计算并显示靶区体积数值，为放疗靶区勾画提供定量参考。

（五）肿瘤运动轨迹预测。系统集成BiLSTM双向长短期记忆网络和TCN时序卷积网络，基于前几个呼吸时相中肿瘤质心的空间坐标，自动预测后续时相中肿瘤的位置变化。预测结果以ECharts交互式折线图呈现，分别展示X、Y、Z三个方向上的位移曲线。观测值与预测值以不同线型和标记区分，用户可自由切换显示真实轨迹和预测轨迹，辅助评估呼吸运动对肿瘤位置的影响。

（六）自定义AI模型管理。系统提供开放的模型管理接口，允许用户上传自行训练的PyTorch格式或ONNX格式的深度学习模型文件。用户可在分割任务和轨迹预测任务中分别激活不同的自定义模型，实现模型的热替换。系统自动识别完整训练检查点文件中的模型权重，兼容多种模型保存格式，降低模型部署门槛。

（七）邮件通知与密码服务。系统集成SMTP邮件发送服务，支持通过163、QQ、Gmail等主流邮箱发送通知。用户在密码重置流程中通过注册邮箱接收6位随机验证码，完成身份验证后设置新密码。管理员批量创建账号时，系统自动向各用户发送包含登录凭据的欢迎邮件。

（八）综合影像浏览。系统集成了Cornerstone.js专业医学图像渲染引擎，支持DICOM图像的窗宽窗位交互调节、鼠标缩放和平移等标准PACS阅片操作。同时提供4D Cine电影播放器，可自动循环播放各呼吸时相的CT序列，直观展示肿瘤随呼吸运动的动态变化。胶片缩略图导航组件支持快速跳转至任意切片层，DICOM元数据面板完整展示患者信息、检查参数和采集参数等标准标签。

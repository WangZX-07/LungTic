# LungTic

LungTic 是面向肺部影像诊疗场景的临床客户端、管理后台与中心服务项目。

项目源码、数据库脚本、部署说明、设计资料和历史材料已经统一整理到 [`web_source`](web_source/)：

- [开发与运行说明](web_source/README.md)
- [项目交接文档](web_source/HANDOFF.md)
- [材料清单](web_source/MATERIALS.md)
- [系统架构](web_source/ARCHITECTURE.md)

仓库不应包含真实病例、生产数据库、TLS 私钥、访问令牌或生产环境变量。构建产物和本地依赖目录也不会提交到 Git。
